# Bust head model (optional)

Drop a human bust/head `.glb` file here as `bust-head.glb` to drive the hero particle system from real mesh vertices (Option A).

If the file is missing, the hero falls back to a procedural 3D bust sampled via `MeshSurfaceSampler`.

Recommended: low-poly head scan or bust, Y-up, roughly unit scale, centered near origin.
